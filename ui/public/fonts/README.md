# Bundled fonts

Geist and Geist Mono, unmodified variable WOFF2 files from the official
[Vercel Geist v1.9.0 release](https://github.com/vercel/geist-font/releases/tag/v1.9.0).

Licensed under the SIL Open Font License 1.1; see `OFL.txt`. Both fonts ship
inside the desktop app and load from its own origin, including when offline.
No font CDN or extra runtime dependency is required.
